# Eigene Videos (optional)

Standard ist YouTube. Nur wenn eine Folge direkt von der eigenen Seite abgespielt werden soll:

1. MP4-Datei hier ablegen, z. B. `Folge01.mp4` (H.264/AAC, möglichst unter 50 MB – GitHub erlaubt max. 100 MB pro Datei).
2. In `../kalender.json` bei dieser Folge `"video": "videos/Folge01.mp4"` eintragen.

Ist `video` gesetzt, hat es Vorrang vor `youtube`.
