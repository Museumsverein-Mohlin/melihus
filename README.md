# Museumsverein Möhlin – Melihus

Öffentliche statische Website für GitHub Pages. Die Dateien aus diesem Ordner bilden die veröffentlichte Website.

## Veröffentlichung

GitHub Pages wird auf Branch `main`, Ordner `/ (root)` eingestellt. Die Datei `index.html` liegt direkt im Stammverzeichnis.

Die Domain `melihus.ch` bleibt bis zur gesonderten DNS-Umstellung beim bisherigen Anbieter.
