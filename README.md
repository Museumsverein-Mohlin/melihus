# Museumsverein Möhlin – Melihus

Öffentliche statische Website, veröffentlicht über GitHub Pages. Die Dateien in diesem Repository bilden die Website.

## Veröffentlichung

- GitHub Pages: Branch `main`, Ordner `/ (root)`. `index.html` liegt im Stammverzeichnis.
- Eigene Domain: `melihus.ch` (eingetragen in der Datei `CNAME`).
- Jede Änderung auf `main` wird automatisch veröffentlicht, meist innerhalb von 1–2 Minuten.

## Aufbau

- `index.html` – Startseite (inkl. Hinweis auf den nächsten Termin)
- `archiv.html` – Fotoarchiv (Bilder in `assets/archiv/`)
- `impressum.html`, `datenschutz.html` – Rechtliches
- `styles.css` – gemeinsames Stylesheet
- `assets/` – Bilder, Logo, PDF

Dieses Repository ist der einzige gültige Stand der Website. Lokale Kopien sind nicht maßgeblich.
